跨物种细胞组成与人脑皮层分层厚度的空间关联

HomoloMap跨物种映射 · Brainnetome 105个皮层区域 · 主分析、敏感性分析与可解释预测

审阅摘要

研究目的：检验猕猴空间转录组所描述的细胞类型空间分布，经转录同源关系和脑区空间映射后，是否与人脑BigBrain六个皮层层次的厚度分布存在系统关联。

主分析：先在猕猴D99空间中按“同一细胞类型跨六层”的比例归一化，再映射到人脑Brainnetome（BN）图谱；映射后重新闭合比例；不进行中心化对数比变换（CLR）；厚度使用每个脑区内六层相对厚度。

主要发现：在外部生物学mask保留的97个“层–细胞类型”组合中，31个关联通过分支内Benjamini–Hochberg假发现率校正（q<0.05）；平均绝对相关系数为0.4576。六层标签的精确置换检验显示正确层序对应显著优于错配（720种排列，p=0.005556）。

稳健性：relabel后闭合与未闭合连续特征的效应高度一致（Pearson r=0.9997；Spearman ρ=0.9997；显著集合Jaccard=1.00），但闭合版本具有更明确的成分数据解释，因此作为主结果。

结论边界：结果支持空间共变与层特异对应，不证明细胞类型导致皮层厚度变化。ROI是空间单元，不是独立受试者。

1. 研究问题与证据链

本分析检验：由猕猴层空间转录组估计并映射到人脑的细胞类型空间分布，是否与 BigBrain 六层厚度呈层特异的空间对应。证据链依次包括特征构建顺序验证、八个 preprocessing 分支的公平比较、空间旋转检验、六层标签精确置换，以及留出 ROI 的预测与 SHAP 贡献分解。

猕猴 D99 layer counts→同源 subclass 映射→组成归一化→D99→BN 连续特征映射→可选 CLR→绝对/相对 BigBrain 厚度→spin + FDR + 层置换 + SHAP

一句话论点：与层内细胞类型平衡相比，同一细胞类型在六层间的相对分配更能解释人脑层厚度的空间组织，但这一关联依赖特征构建顺序、跨物种映射和外部层存在 mask，不构成细胞类型对层厚度的因果证明。

数据对象与分析流程（详细说明）

数据来源与分析单位

细胞组成来自猕猴空间转录组。原始226个细胞类型中，191个具有可用的转录同源映射，35个未解析类型被记录并排除，最终聚合为23个细胞亚类。人脑表型来自BigBrain六层组织学厚度；两类数据对齐至Brainnetome图谱的105个皮层区域。

为什么先归一化、再relabel、再reclosure

“within-layer”回答同一皮层层内不同细胞类型如何构成；“within-region cross-layer”回答给定细胞类型在同一脑区六层之间如何分配。主问题关注细胞类型的层间配置，因此选择后者。空间relabel是加权汇总，会因源区覆盖度和权重使总和偏离1，所以映射后必须再次reclosure。该步骤恢复成分解释，同时不改变组分间的相对关系。映射审计发现D99标签106、118和194没有目标对应，报告中持续保留这一atlas覆盖风险。

为什么主分析不用CLR

CLR适合分析“一个封闭组成内部各成分相对于几何均值的变化”。但跨层归一化后，研究对象已是每个细胞类型在六层中的分配；随后按单层对23个细胞类型做CLR，会把问题改写成层内细胞类型平衡。八分支结果显示这种改写在主设置下减少显著发现，因此主分析保留原比例，CLR作为敏感性分支。

厚度的两种表达

绝对厚度保留脑区总体尺度差异；相对厚度把每个ROI的六层厚度除以总皮层厚度，聚焦层间构成。相对厚度与跨层细胞分配在统计对象上更直接对应，因此在有整体层序证据且局部关联更强时被选为主分析。

空间相关、FDR与整体置换

每个生物学mask保留的层–细胞类型组合在105个皮层区域上计算Pearson相关，并以1,000次Alexander–Bloch皮层旋转构建空间零分布，获得双侧p值。每个分析分支内部对97个有效组合执行Benjamini–Hochberg校正；八个分支之间不再进行第二层校正，因此跨分支差异用于评价方法敏感性，而不作为八次独立验证。整体层序检验枚举六层的6!=720种排列，以所有有效组合的平均相关作为统计量，采用单侧greater检验；由于完整枚举已包含观测identity，精确p值按极端排列数除以720计算。

预测与SHAP优势分析

预测模型采用五折交叉验证的岭回归，每个脑区的预测均由未包含该脑区的训练数据产生。标准化只在各训练折拟合，避免测试信息泄漏；正则化强度在10−3至103的25个候选值中选择。随后以SHAP值汇总23个细胞类型的绝对预测贡献，并进一步聚合至兴奋性、抑制性和非神经元类别。该结果反映模型对各类特征的依赖程度，不能单独作为生物学因果证据。

3. 八分支设计与统计方法

固定D99来源空间归一化后以mean进行D99→BN连续特征映射，比较两种归一化方向（层内、同一细胞类型跨层）、CLR开关和厚度尺度（绝对、相对），共8个分支。所有分支共享23个subclass、105个ROI、97个mask后检验、seed=42及同一组1,000次Alexander–Bloch空间旋转。

局部空间检验

每个有效layer–cell-type pair计算Pearson r及spin p值。随后在该分支全部97个有效p值上一次性执行Benjamini–Hochberg校正，阈值q<0.05。未对8个pipeline之间再做第二层多重校正。

整体层序检验

枚举六层标签的6!=720种排列，以全部有效关联的平均r作为统计量，检验正确层对应是否位于单侧零分布右尾。经验p采用(extreme+1)/(n+1)。identity排列在720种精确枚举中只计数一次。

此外，五折留出ROI的RidgeCV评估空间外推预测；SHAP仅描述模型预测中的特征贡献，不是显著性检验，也不支持因果解释。

3.2 精确置换实现审计与校正

whole-match校正。六层标签共有6!=720种完整排列，观测identity已经包含其中。原实现仍使用Monte Carlo抽样所需的“+1”估计，等于把观测排列重复计数一次。校正后采用 extreme / 720；主分支有4个排列达到或超过观测统计量，因此p由5/721=0.006935改为4/720=0.005556，整体层序结论保持显著。

mismatch校正。原实现为每个层–细胞类型组合枚举600个错配排列，但单个组合实际只有5个不同的目标层，每个目标被重复120次。校正后使用5个唯一错层相关，加上观测匹配构成6个等权指派，精确p为(1+k)/6。其最小可能p为1/6，因此原报告中的pair级mismatch FDR发现不成立；八个分支校正后均为0项。该变化不影响基于1,000次空间spin的97项局部关联，也不影响whole-match整体层序证据。

5. 最终 pipeline 的选择与解释

跨层归一化

研究对象是给定细胞类型在六层之间的分配。跨层归一化与六层相对厚度在统计对象上直接对应；平均来看，跨层分支比层内分支增加8.5个FDR发现，mean |r|提高0.0437，但优势主要由无CLR条件驱动。

不使用CLR

跨层归一化后，再对每层细胞类型做CLR会把问题改写为层内细胞类型对数比平衡。在相对厚度条件下，CLR使FDR发现从31降至11，mean |r|从0.4576降至0.2971；这支持保留原跨层分配特征。

相对厚度

相对厚度去除ROI总厚度尺度，突出六层内部厚度构成。在跨层、无CLR条件下，相对厚度较绝对厚度增加10项FDR发现，mean |r|提高0.0491；两者的整体层序检验均为p=0.005556，说明相对化增强局部效应但不是整体层序证据的唯一来源。

SHAP整体贡献

贡献分散表明预测不是由单一细胞类型支配。Chandelier、L6 CT、L5/6 NP、Pax6和Lamp5_Lhx6构成前五，但这些数值仅表示在当前相关特征与Ridge模型中的预测分摊；相关特征间的共享信息可改变SHAP排序，因此不应将其解释为独立生物效应大小。

分层SHAP：贡献来源具有明显的层特异性

上述总体贡献不是将六层堆叠为一个预测任务，而是分别在L1–L6训练六个模型，再对各层SHAP贡献取平均。为避免平均值掩盖层差异，本次进一步保留每层的折外预测、细胞类型贡献和细胞大类贡献。每层均使用105个Brainnetome脑区、五折out-of-fold RidgeCV及训练折内标准化；完整23类组成在relabel后重新闭合，外部mask只决定该层进入模型的细胞类型。

综合解释。六层并不共享单一首要细胞类型，支持层特异的多细胞组织模式。L4和L6兼具较高预测性能与较分散贡献，更适合形成候选解释；L1的Sncg占41.2%，但该层仅有8个mask保留特征且OOF R²为0.231，高集中度可能部分源于较小的特征集合。分层SHAP仍是模型解释，不是独立显著性检验，也不证明细胞类型对层厚度的因果作用。

6. 稳健性、替代解释与分析边界

  • 探索性选择：八个pipeline使用同一数据比较后按FDR发现数和mean |r|选择最终分支。分支内FDR控制不等于对“八分支搜索”进行校正；独立确认应预先固定pipeline。
  • 空间零模型：spin检验控制皮层空间自相关，但结果仍依赖BN分区、所用皮层表面、Alexander–Bloch旋转及仅1,000次旋转所决定的p值分辨率。
  • 跨物种映射：原始猕猴细胞类型向人类subclass的同源映射存在多来源与未解析类别；D99→BN映射每层丢弃标签106、118和194。映射误差会传递至相关与SHAP。
  • 相关而非因果：层厚度与估计细胞类型分布的空间共变不能确定发育、细胞密度或层厚度变化的因果方向。
  • 组成解释：非CLR分支的各特征不是相互独立的绝对效应；未闭合敏感性特征不满足严格闭合，而reclosure主分析已在BN目标空间满足闭合约束。

7. 补充敏感性分支：within-layer + CLR + absolute thickness

该分支具有最高平均OOF R²（0.618）和14项FDR发现，但整体层序统计量为−0.0789，p=0.636111。它说明层内对数比特征可以预测厚度，却不支持六层按正确层序形成整体匹配，因此保留为替代问题定义下的敏感性结果。

结果解释：可以说什么、不能说什么

支持的解释：同源细胞类型的层间空间分配与人脑皮层相对层厚度之间存在有层次选择性的空间共变；这种对应不是仅由皮层平滑空间梯度造成，因为局部检验使用了空间旋转零模型，整体层序也优于错配层序。

SHAP层面的解释：模型贡献分布较为分散而非由单一细胞类型垄断。重闭合主分支的折外R²为0.5207，平均折外Pearson相关为0.7124；最高单一贡献为Chandelier subclass（相对贡献0.0782），前五项合计0.3233。类别汇总为抑制性0.4155、兴奋性0.3985、非神经元0.1860。它们反映预测依赖度，不表示相应细胞群直接调控厚度。

替代解释：共同发育梯度、皮层层级、髓鞘化、细胞密度、供体和物种差异、图谱边界及跨物种映射误差都可能同时影响两类空间图。当前设计降低了空间自相关和处理流程选择带来的偏差，但不能排除这些混杂。

证据等级：“31项FDR关联”和“whole-match p=0.005556”属于本数据集内的统计证据；“闭合前后高度一致”属于处理稳健性证据；“细胞类型塑造人类皮层层厚度”仍是假说，需要独立数据、其他供体或物种复现及机制实验验证。

8. 结论与下一步验证

现有证据支持把“跨层归一化、无CLR、相对厚度”作为后续主分析pipeline：它与层间分配这一科学问题一致，并在局部空间效应、整体正确层序与解释性预测三类证据之间取得最平衡的表现。结果同时划定了明确边界：层内CLR更偏向预测而非正确层序，处理顺序可在Layer IV产生方向反转，且主特征在BN空间不是严格闭合组成。

最有价值的下一步不是继续增加同一数据上的候选pipeline，而是固定当前pipeline，在独立供体或替代人脑层厚度数据上复现31项FDR发现、整体层序统计量和reclosure后的主要SHAP贡献；若目标改为严格的BN组成解释，则应在relabel后重新闭合，并将该版本作为独立、预先定义的分析重新测试。
